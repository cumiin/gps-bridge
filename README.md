# GPS Bridge

GPS 없는 **안드로이드 태블릿**에, **안드로이드 폰**의 GPS를 WiFi(핫스팟) 또는 블루투스로 보내
내비게이션을 쓸 수 있게 해주는 앱 한 쌍입니다.

- **sender** : 폰에 설치 (GPS 읽어 전송)
- **receiver** : 태블릿에 설치 (수신 → 모의 위치로 시스템에 주입)
- **common** : 두 앱이 공유하는 프로토콜/데이터 모델

원리: 수신 앱이 안드로이드 **모의 위치(Mock Location)** 로 좌표를 주입하면,
구글맵·오프라인 지도앱 등이 태블릿 자체 GPS인 것처럼 인식합니다.

---

## 1. 빌드 방법 (Android Studio 권장)

1. **Android Studio** 설치 (Hedgehog 이상 권장)
2. Android Studio → **Open** → 이 `gps-bridge` 폴더 선택
3. 첫 열기 시 Gradle 동기화가 자동 실행됩니다.
   (이 프로젝트에는 gradle wrapper `.jar` 바이너리가 빠져 있으니,
    Android Studio가 자동 생성하도록 두거나 아래 명령으로 만드세요.)
   ```bash
   gradle wrapper --gradle-version 8.7
   ```
4. 상단 모듈 선택에서
   - `sender` 를 골라 **폰**에 실행/설치
   - `receiver` 를 골라 **태블릿**에 실행/설치

APK만 뽑으려면: **Build → Build Bundle(s)/APK(s) → Build APK(s)**
결과물은 `sender/build/outputs/apk/` 및 `receiver/build/outputs/apk/` 에 생성됩니다.

> 명령줄 빌드: `./gradlew :sender:assembleDebug :receiver:assembleDebug`

---

## 2. 태블릿(수신) 준비 — 최초 1회

1. **설정 → 태블릿 정보 → 빌드 번호 7번 연타** → 개발자 모드 활성화
2. `GPS Bridge 수신` 앱 실행 → **[개발자 옵션 열기]** 버튼
3. 개발자 옵션에서 **"모의 위치 앱 선택"** → **GPS Bridge 수신** 지정
4. 앱 실행 시 위치 권한 허용

> ⚠️ 이 단계를 안 하면 수신 앱이 "모의 위치 앱으로 지정되지 않았습니다" 오류를 냅니다.

---

## 3. 사용법

### A. WiFi / 핫스팟 (권장)

1. **폰에서 핫스팟 켜기** → 태블릿을 그 핫스팟에 연결
   (또는 폰·태블릿을 같은 공유기 WiFi에 연결)
2. **태블릿(수신 앱)**: `WiFi/핫스팟` 선택 → 포트 `50505` → **시작**
   → "WiFi 수신 대기 중" 표시
3. **폰(송신 앱)**: `WiFi/핫스팟` 선택
   - 대상 IP: `255.255.255.255` (브로드캐스트, 기본값) 그대로 두면 됨
   - 잘 안 되면 태블릿 IP를 직접 입력 (태블릿 설정 → WiFi에서 확인)
   - 포트 `50505` (수신과 동일) → **시작**
4. 태블릿에 "수신 중 (n) …" 이 올라가면 성공.
   태블릿에서 구글맵/내비 실행 → 폰 위치로 따라감

### B. 블루투스

1. 폰과 태블릿을 **블루투스 페어링**
2. **태블릿(수신 앱)**: `블루투스` 선택 → **시작** → "연결 대기 중"
3. **폰(송신 앱)**: `블루투스` 선택 → 목록에서 태블릿 선택 → **시작**
4. 연결되면 태블릿에 "수신 중 …" 표시

## 4. 자주 겪는 문제

| 증상 | 해결 |
|------|------|
| 수신 앱이 "모의 위치 앱으로 지정되지 않음" | 개발자 옵션 → 모의 위치 앱 = 수신 앱으로 지정 |
| WiFi인데 수신이 0건 | 대상 IP를 브로드캐스트 대신 **태블릿 실제 IP**로 입력 |
| 내비가 위치를 안 잡음 | 태블릿 위치(GPS) 스위치가 켜져 있는지 확인 |
| 티맵 등 일부 내비가 무시 | 모의 위치 차단 앱. 구글맵·OsmAnd·맵스미 등으로 테스트 |
| 폰이 위치를 못 보냄 | 폰 위치(GPS) 켜기, 실외에서 GPS 고정 후 재시도 |
| 백그라운드에서 끊김 | 두 앱 모두 배터리 최적화 예외로 설정 |

## 5. 구조

```
gps-bridge/
├── common/    프로토콜(GpsData, Protocol)
├── sender/    폰용 송신 앱 (UDP/Bluetooth 전송)
└── receiver/  태블릿용 수신 앱 (모의 위치 주입)
```

전송 포맷(한 줄): `GPSB,위도,경도,고도,정확도,속도,방위,시간(ms)`

## 참고 / 주의

- 안드로이드 → 안드로이드 조합에서만 동작합니다. (아이패드 수신 불가)
- 모의 위치는 개인 용도(내비 사용)로만 쓰세요. 위치 스푸핑을 금지하는
  앱/서비스에서는 사용하지 마세요.
